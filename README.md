## Description
```bash
An ingredient substitution engine aimed at helping users find substitutes that may
not be locally available when outside of their home country.
```
---
## Setup

### First-Time Setup

1. Navigate to the project directory

2. Activate/create python virtual environment

3. Install dependencies
```bash
   pip install customtkinter maturin
```

4. Initialize maturin — select **pyo3** when prompted
```bash
   maturin init
```

5. Run this command for initialization and when modifying:

```bash
maturin develop
```

6. Run db.py directly to build the database

---

### Development

After modifying Rust code, rerun this command:

```bash
maturin develop
```
